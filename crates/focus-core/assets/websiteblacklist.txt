# FocusMode — lista rozpraszających stron (websiteblacklist.txt)
#
# Strony z tej listy są blokowane tylko w czasie skupienia (w przerwie i po Stop działają normalnie).
# Jedna pozycja w linii. Linie zaczynające się od # to komentarze; puste linie są pomijane.
#
# • Zwykła domena, np.  kwejk.pl
#   Blokuje domenę i wszystkie jej subdomeny (www.kwejk.pl, m.kwejk.pl…). Adres z https:// i ścieżką
#   też zadziała, ale liczy się tylko domena: https://www.reddit.com/r/polska blokuje cały reddit.com.
#   Adres ze znakiem ? (np. youtube.com/watch?v=…) jest już wyrażeniem regularnym — wpisz samą domenę.
#
# • Wyrażenie regularne — linia w ukośnikach /…/ albo zawierająca któryś ze znaków  \ ^ $ * + ? ( ) [ ] { } |
#   Dopasowywane do całego adresu strony (np. https://www.youtube.com/shorts/abc), bez rozróżniania
#   wielkości liter. Składnia RE2 (jak w Chrome): bez lookahead i odwołań wstecznych. Kropka to „dowolny znak”,
#   więc w domenach pisz \. — np.  youtube\.com/shorts  blokuje tylko Shorts, a nie cały YouTube.
#
# Plik wczytuje się ponownie sam po zapisaniu (albo przyciskiem „Wczytaj ponownie” w Ustawieniach).
# Żeby odblokować stronę, usuń linię albo dopisz na jej początku #.
# Blokada w przeglądarce działa przez rozszerzenie FocusMode; bez niego aplikacja tylko upomina,
# gdy tytuł okna przeglądarki pasuje do listy.
